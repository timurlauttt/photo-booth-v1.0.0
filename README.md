## ✨ Fitur Unggulan

- 📁 **Upload Foto dari Galeri**: Bebas memilih antara berfoto langsung lewat kamera atau mengunggah koleksi gambar dari galeri HP/laptop (mendukung batch upload dan drag & drop).
- 🖐️ **Hands-Free Gesture (Isyarat 5 Jari)**: Memotret dari kejauhan cukup dengan membentangkan kelima jari ke arah kamera (didukung oleh MediaPipe AI Vision offline).
- 🎞️ **Filter Retro & Digicam Y2K**: Pilihan filter vintage otentik (*Light Leak 35mm*, *Film Grain 800*, *Lo-Res Story*, *Golden Hour*, *Anime Pastel*, *Cyberpunk*, dan *B&W High Contrast*).
- 🖱️ **Stiker Bebas Geser (Drag & Drop)**: Tambahkan stiker lucu dan seret bebas ke posisi mana pun di atas strip foto Anda.
- 🔄 **Retake Pose Tertentu**: Kurang pas dengan salah satu pose? Klik foto tersebut dan ulangi pose itu saja tanpa menghapus foto lainnya.
- 📦 **3 Format Ekspor Hasil**:
  - **Foto Strip PNG**: Gambar beresolusi tinggi dan jernih, siap cetak fisik.
  - **Video Stop-Motion MP4 (9:16)**: Kartu animasi vertikal pas untuk Instagram Story, TikTok, dan WhatsApp Status.
  - **Animasi GIF Loop**: File GIF berulang tanpa putus dengan *Floyd-Steinberg Error Diffusion Dithering*.
- 🛡️ **Jaminan Privasi 100% Lokal (Zero Server Upload)**: Seluruh pemrosesan foto, video, dan AI berjalan murni di peramban (*client-side*). Tidak ada foto yang dikirim ke internet.
- 💡 **Virtual Ring Light & Mode Full (Fullscreen)**: Pencahayaan ekstra untuk ruangan temaram dan sensasi bilik foto arcade nyata.

## 📖 Buku Panduan Penggunaan (Guidebook Pengguna Awam)

### 1. Cara Cepat Memulai Sesi Foto
1. **Buka Website**: Izinkan peramban (browser) untuk mengakses kamera Anda saat diminta.
2. **Pilih Tata Letak (Layout)**:
   - Pilih jumlah pose yang Anda inginkan (misalnya: *4 Pose Klasik*, *3 Pose Kotak*, atau *6 Pose Extended*).
3. **Pilih Filter & Frame**:
   - Di panel kamera, pilih filter warna favorit Anda (seperti *Normal*, *Light Leak 35mm*, atau *Film Grain*).
   - Pada tab **Kustomisasi**, tentukan warna dasar bingkai serta pola latar (seperti *Papan Catur*, *Polkadot*, atau *Kertas Kotak*).
4. **Mulai Memotret**:
   - Tekan tombol kuning **MULAI FOTO**, atau aktifkan fitur **Isyarat Tangan (Hands-Free)**.
   - Bersiaplah bergaya mengikuti hitungan mundur di layar!

---

### 2. Panduan Fitur Hands-Free (Isyarat 5 Jari)
Ingin foto bersama teman dari kejauhan tanpa harus bolak-balik menekan layar?
1. Nyalakan tombol **GESTURE** di pojok kontrol kamera hingga berstatus **ON**.
2. Angkat tangan Anda menghadap ke lensa kamera dan **bentangkan kelima jari lurus** (seperti memberi isyarat *High Five* atau angka 5).
3. Tahan posisi telapak tangan Anda selama kurang lebih **0,5 detik**.
4. Tulisan hijau *"ISYARAT 5 JARI TERDETEKSI"* akan muncul dan hitungan mundur kamera akan otomatis dimulai!
> *Tips: Fitur ini memiliki jeda pendinginan (cooldown 4,5 detik) sehingga Anda tidak perlu khawatir kamera memotret terus-menerus tanpa sengaja.*

---

### 3. Panduan Kustomisasi Stiker & Cap Tanggal
1. **Menempelkan Stiker**:
   - Masuk ke tab **Kustomisasi** di sebelah jendela bidik kamera.
   - Klik stiker yang Anda sukai (emoji, pita, bintang, dsb.). Stiker akan langsung muncul di atas foto.
   - **Klik dan geser (drag & drop)** stiker tersebut ke posisi mana saja sesuka hati.
2. **Cap Tanggal Digicam (Orange Quartz)**:
   - Aktifkan menu *Cap Tanggal Digicam* untuk mencetak stempel tanggal digital warna oranye menyala khas kamera saku jadul tahun 90-an/2000-an di sudut kanan bawah setiap foto.
3. **Teks Caption Custom**:
   - Ketikkan kalimat atau nama Anda di kolom caption dan pilih gaya font (*Retro Typewriter*, *Marker Handwritten*, *Y2K Cyber*, dsb.).

---

### 4. Panduan Retake Pose (Ganti Pose yang Kurang Pas)
Jika dari 4 pose yang diambil, ada salah satu pose yang Anda kurang suka (misalnya mata terpejam):
1. **Klik foto tersebut** pada pratinjau strip foto di sebelah kanan (atau tab strip pada ponsel).
2. Tekan tombol kuning **RETAKE POSE**.
3. Kamera akan menghitung mundur dan **hanya mengambil ulang foto pada slot tersebut**, sementara foto-foto lainnya tetap aman.

---

### 5. Panduan Mengunduh Hasil Foto
Setelah sesi selesai, Anda dapat memilih format unduhan di bawah strip foto:
- **UNDUH FOTO (PNG)**: Mengunduh foto strip resolusi tinggi untuk dicetak atau disimpan ke galeri.
- **MP4 STORY (IG / WA)**: Mengonversi foto-foto Anda menjadi video stop-motion animasi vertikal yang sangat pas untuk dibagikan ke Instagram Story atau WhatsApp Status.
- **GIF LOOP**: Mengunduh animasi gambar bergerak retro berulang tanpa suara.
- **BAGIKAN**: Membuka menu bawaan perangkat Anda untuk langsung mengirimkan foto ke WhatsApp, Gmail, AirDrop, atau media sosial.

## 🔒 Privasi & Keamanan (Zero Server Upload)

Aplikasi ini mengedepankan privasi 100%:
- **Zero Server Upload**: Foto, video, dan proses pengenalan gestur tangan diproses secara lokal di memori perangkat Anda (*Client-Side WebAssembly & Canvas API*).
- **Tanpa Database & Tanpa Akun**: Tidak ada pendaftaran, login, atau pengumpulan data pribadi apa pun.
- **Aman Digunakan**: Saat tab browser ditutup atau tombol *Reset* ditekan, seluruh rekaman foto di sesi tersebut otomatis terhapus dari memori.

## 🛠️ Panduan Pengembang (Developer Setup)

Proyek ini dibangun menggunakan **React 19**, **Vite**, **TailwindCSS**, dan **WASM**:

```bash
# 1. Klon repositori
git clone https://github.com/timurlauttt/photo-booth.git
cd photo-booth-v1.0.0

# 2. Instal dependensi
npm install

# 3. Jalankan server lokal pengembangan
npm run dev

# 4. Uji linter dan build produksi
npm run lint
npm run build
```
